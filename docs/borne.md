# Préparer la borne

Cette documentation est désormais intégrée à l'application : ouvrez le menu **Aide** puis **Bornes** (`http://localhost:<port>/Aide/Bornes`, sur le poste du responsable). Elle couvre l'adresse de la borne, la liaison, le mode kiosque (Windows/Edge avec script, Android, iPad) et le dépannage.
